# JM Research website — free starter

This is a responsive, static website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — layout, colours and responsive design
- `script.js` — mobile navigation and enquiry form
- `README.md` — setup and publishing instructions

## Before publishing
1. Open `script.js` in a text editor.
2. Replace `your-email@example.com` in `CONTACT_EMAIL` with your real enquiry email.
3. In `index.html`, replace the email/social placeholders with your real contact details and links.
4. Review the course descriptions and add only confirmed course dates, fees, syllabus, videos and enrolment information.
5. Test the site by opening `index.html` in a browser.

The enquiry form uses the visitor's email app (`mailto:`); it does not store or transmit messages by itself. A server-side form service would be needed for submissions without an email app.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new **public** repository, for example `jm-research`.
3. Upload the four files in this folder to the repository root.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then Save.
7. Wait for GitHub Pages to publish. Your site URL will look like `https://YOUR-USERNAME.github.io/jm-research/`.

GitHub Pages supports static HTML, CSS and JavaScript sites. A custom domain is optional and normally costs money.

## Important
This is a front-end starter site, not a full learning-management system. It does not yet include student accounts, paid enrolment, a course database, quizzes with saved scores, or video hosting. You can link to publicly available YouTube videos and free resources. Do not upload copyrighted material unless you have permission.
